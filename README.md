# changeof-third-party-sources

Third-party source archives and original licence/build materials retained for change of. Proprietary application source and personal user inputs are not published here.

## Downloads

Source materials are attached to [Releases](https://github.com/4dbdjf5mph-creator/changeof-third-party-sources/releases) when available. For the retained set associated with private app 0.88.0+167 and diagnostic packaging revision 1.0.169.0, download all three ThirdPartySources-167-review-*-of-03.zip assets. Each ZIP opens independently; extract each to a separate folder. SOURCE-INDEX.json identifies component archive locations, and SHA256SUMS.txt verifies the downloads.

GitHub's automatically generated Source code (zip) and Source code (tar.gz) snapshots do not replace the attached third-party source archive set.

## Original terms

Original third-party licences and notices apply to their respective materials. No blanket repository licence replaces those terms. Providing these retained materials does not itself certify complete Corresponding Source or resolve pending product-wide redistribution conditions. A source-material release is not an application release.
